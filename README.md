# 《心动失焦》· 番茄互动剧配置工作台 V0.1（源代码）

## 文件结构

- `index.html`：UI 页面骨架，引用 CSS 和 JavaScript。
- `styles.css`：所有视觉样式。
- `app.js`：本地数据、编辑表单、校验、JSON/CSV/TXT 导入导出等功能。
- `心动失焦_示例配置.json`：第一章部分内容及五章章节占位示例；并非正式可提交版本。

## 运行方式（不需要安装依赖）

1. 解压整个压缩包，保持 `index.html`、`styles.css`、`app.js` 在同一文件夹。
2. 使用 Chrome 或 Edge 打开 `index.html`。
3. 示例已内置在 `app.js` 的 `fresh()` 函数内。如需导入示例文件，点击右上角 **导入 JSON**。
4. 修改后点 **保存项目 JSON**，下载当前数据；下次打开页面时需手动导入 JSON 文件。页面**不会自动保存**。
5. 在“校验与填报”页面生成文本填报单；CSV 可以用于内部协作，但不属于番茄平台官方导入格式。

## 用 VS Code 修改

1. 用 VS Code 的 **File > Open Folder** 打开解压目录。
2. 改布局/文字：`index.html`；改颜色/样式：`styles.css`；改字段/功能：`app.js`。
3. 浏览器刷新即可查看修改，注意浏览器刷新会把页面中尚未导出的编辑数据重置为内置演示数据。

## 安全与边界

- 工具当前是**纯前端离线应用**，没有后端、登录、多人实时协作或自动同步。
- 未连接番茄小说平台；不提供自动视频上传、API 写入或一键提交。
- 请勿把平台访问令牌或个人账号密码写入源码或 JSON 文件。
- 程序没有依赖外部 CDN，也不需要网络。JSON/CSV/TXT 下载均由本地浏览器生成。
- 平台自动生成的节点 ID、视频顺序编号、版权中台 ID、数值变化必须经策划/技术确认。

## 后续接入 GitHub 建议

把本文件夹作为项目仓库中的独立目录（例如 `tools/fanqie-config/`）。建议一人维护核心 JSON 或按章节拆分后再提供合并功能；当前 V0.1 没有自动合并，多人同时编辑同一 JSON 易发生覆盖。
